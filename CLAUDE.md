# AllHikes

Hiking-tour aggregator for Armenia: a separate brand from yerevent. The owner (Anna) is
non-technical, so explain things in plain words.

## Layout

- `assets/app.js`: every page's behaviour and all UI text (en/hy/ru, the `T` object). Each
  page's `<body>` says which view it is (`data-page="home" | "clubs" | "club"`) and the path
  back to the site root (`data-root`), so links work both at a sub-path and on a custom domain.
- `assets/style.css`: the look (tokens at the top, light and dark).
- `assets/logos/<instagram handle>.jpg`: club logos, 160px (`scripts/fetch_logos.py`).
- Generated by `scripts/build.py`, don't hand-edit: `assets/data.js`, `index.html`,
  `clubs/index.html`, `clubs/<slug>/index.html`.
- `data/`: `hikes-raw.json` (Esora), `hikes-ig.json` (Instagram via Bright Data + Claude),
  `clubs.json` (the club list and contacts; set `active: false` to hide one),
  `trails.json` + `places.json` (OpenStreetMap). Don't hand-edit the generated ones.

## Rules worth keeping

- "big" listings (3+ days, or more than 60 days away) go to the Ararat table and big-trips
  section. Their prices under 6,000 are dollars even though Esora says AMD.
- Difficulty: the club's own words first, otherwise estimated from km and climb, marked "~".
- Map pins come from matching the hike's name to OpenStreetMap places; trails are OSM
  `route=hiking` relations within 2.5 km of the pin or named in the hike. Credit
  "© OpenStreetMap contributors" wherever maps or trails appear.
- AllTrails forbids scraping, copying and embedding its trails; HIKEArmenia has no licence or
  API. Don't use either source's data without written permission.
- Browsers often have no Armenian date names, so `fmtDate` builds Armenian dates by hand.
- Keep `noindex` in the page heads until Anna says clubs have agreed to be listed.

## Automatic jobs (.github/workflows)

- `update.yml`: daily, Esora then build. `instagram.yml`: weekly, needs secrets
  `BRIGHTDATA_TOKEN` and `ANTHROPIC_API_KEY`, capped at 600 Bright Data records a month.
  `trails.yml`: monthly OpenStreetMap refresh.

Check a change: `python scripts/build.py`, `python -m http.server 8767`, open it at phone
width (430px), and switch through all three languages on the home, clubs and one club page.

## Telegram Mini App

The same site opens inside Telegram (bot @AllHikesArmeniaBot) from the bot's menu button (set in @BotFather to
`https://apricot-stone.github.io/allhikes/`). There is no separate app and no server. `app.js` spots
Telegram by the `#tgWebAppData` it adds to the first URL and remembers that, plus the language and
light/dark, in sessionStorage. It only loads Telegram's script there. Inside Telegram it uses
Telegram's colours, shows Telegram's back button on inner pages and the map popup, opens outside
links in the right app, and gives a small vibration on taps. The normal website is unchanged.

### Sign-ups ("I'm going")

Inside Telegram only, each hike card has an "I'm going" button, and the home page shows
"My hikes" at the top. It doesn't book a place: people still book with the club, and the app
tells them so. Sign-ups go to `backend/Code.gs`, an Apps Script in the "AllHikes sign-ups"
Google Sheet (tab `Signups`). It checks Telegram's signature with the script property
`BOT_TOKEN` and sends a reminder at 18:00 Yerevan time the day before. Its web app URL goes
in `API` near the top of `app.js`; while that's empty the button stays hidden. Hikes get a
stable `id` in `build.py` (Esora slug, else a hash of the link and date).

### Club contact, My hikes, booking status

- Hike cards show one contact button per club: its Telegram chat if it has one (a person's
  account first, then a group), else Instagram DMs (`ig.me/m/<handle>`). Channels are never used
  because people can't write there. `scripts/check_telegram.py` sorts the links (it saves
  `telegram_kinds` and `chat` in `data/clubs.json`); run it after changing Telegram links.
- `outreach/club-contacts.xlsx` lists every club's contacts and which button it gets:
  `python scripts/contacts_sheet.py` (needs openpyxl).
- `me/` is the My hikes page. Inside Telegram there's a bottom tab bar (Hikes, My hikes, Clubs).
  The Telegram account is the AllHikes account; the backend keeps a "Users" tab.
- Booking status is set by the person ("I've booked") and saved in the sheet's `booked` column.
  Reminders say "have a great hike" when booked, or "message the club" when not.
- The plain website shows "N going" (public counts from the backend's GET) but no buttons.
- After changing `backend/Code.gs`, Anna pastes it into Apps Script and redeploys the SAME
  deployment (Manage deployments → edit → New version) so the URL in `API` stays the same.
